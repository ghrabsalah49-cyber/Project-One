# Project One – Leon Web Page

## Project Description
This project is a simple web page created as part of an HTML assignment. It presents a Leon-themed landing page with a header, a navigation menu, and a welcome section.

## Technologies Used
- **HTML5** – structures the content of the page.
- **CSS3** – styles the layout and visual elements.
- **Font Awesome** – provides icon assets.
- **Google Fonts (Work Sans)** – provides the page typography.

## Page Sections
1. **Header:** Displays the website logo and a navigation menu with links labeled Services, Portfolio, About, and Contact.
2. **Landing Section:** Displays the heading "Hello There" and a short introduction to Leon.

## Project Files
- `index.html` – the main HTML page.
- `Css/` – the project's stylesheets, including layout, normalization, and icon styles.
- `images/` – images used by the website, including the logo and landing image.
- `webfonts/` – font files used by the icon library.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Notes
The HTML file includes comments identifying important parts of the page, such as the header and landing section. This repository contains the source files for the assignment.
